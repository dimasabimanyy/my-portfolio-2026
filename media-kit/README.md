# Dimaslab Media Kit

A simple static creator media kit built with HTML, CSS, and vanilla JS.

## Run locally
Open `index.html` in a browser.

## Customize
- Replace files in `assets/` with your profile and Reel thumbnails.
- Replace audience placeholder values in `index.html`.
- Replace collaboration rates in `index.html`.
- Update the date in the navigation.
- The Performance chart data is in `script.js`.

## Export PDF
Open the page in Chrome/Safari and use **Print → Save as PDF**. The CSS includes print styles.

## Notes
- Chart.js is loaded from jsDelivr.
- Instagram profile link is set to @dimaslab_.
- Performance figures are based on the Instagram Insights supplied for the last 30 days.
